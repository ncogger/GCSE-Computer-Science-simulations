Binary register playground

GCSE Computer Science · Edexcel 2.1.1–2.1.5

How to use this playground

An 8-bit register is a row of 8 bits. Click any bit to switch it between 0 and 1.

  • Convert – binary ↔ denary, number of patterns, two’s complement.
  • Add – add two binary numbers column by column and see overflow happen.
  • Shift – logical and arithmetic shifts, left and right.
  • Challenge – practice questions on the current tool.
  • Presenter mode hides the explanations and makes everything bigger for a projector.
