How to use this simulation

A small program is stored in main memory. Step through it to watch the CPU fetch each instruction, decode it and execute it, and see which bus is used at each moment.

  • Revision mode shows a full explanation of every step on the right.
  • Presenter mode hides the explanations and enlarges everything for a projector. A one-line caption stays at the bottom.
  • Predict asks you what will happen before each step is shown.
  • Click any memory location to change what is stored there.

A real 8-bit CPU: the Zilog Z80

The Z80 (1976) was the CPU in home computers such as the ZX Spectrum. It connects to the rest of the computer through 40 metal pins. Each pin is one wire, so each pin carries one bit at a time: on (1) or off (0).

Choose a bus to highlight its pins, or click any pin.

Click a pin to find out what it does.
  • Address bus: 16 pins, so 216 = 65,536 different addresses (64 KiB of memory).
  • Data bus: 8 pins, so it moves 8 bits (1 byte) at a time. That’s why it is called an 8-bit CPU.
  • Control bus: pins such as RD (read), WR (write) and CLK (clock).
  • The simulation’s CPU has 4 address wires (24 = 16 locations), 8 data wires and 3 control wires.
  • Modern desktop CPUs have well over 1,000 contacts – Intel’s LGA 1700 socket has 1,700.

A line over a pin name means that signal is “on” when the wire is at 0 volts. You don’t need to know this for GCSE.
