Latin-subset woff2 files from Google Fonts, used by `tools/apply_house_style.py`:

- Atkinson Hyperlegible Next (variable, 400–700) – Braille Institute, SIL Open Font Licence 1.1
- Atkinson Hyperlegible Mono (variable, 400–700) – Braille Institute, SIL Open Font Licence 1.1
- Lexend (variable, 500–700) – The Lexend Project, SIL Open Font Licence 1.1

The OFL allows these fonts to be embedded and redistributed with the simulations.
