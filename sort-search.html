GCSE Computer Science · Edexcel 1.2.6–1.2.7

How to use this simulation

Pick an algorithm, then step through it one comparison at a time. The counters show how much work it is doing, and the code shows which line is running.

  • Compare races two algorithms on the same data, one comparison per tick.
  • Predict asks you what will happen at each comparison before it is shown.
  • In the searches, click any card to search for that value.
  • Presenter mode hides the explanations and makes everything bigger.
